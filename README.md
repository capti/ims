# ims
Репозиторий для практических работ по дисциплине "Интегрированные системы управления"

## Практические работы

- [Практическая работа 1](lab_1.ipynb) — работа с pandas: базовые операции над DataFrame.
- [Практическая работа 2](lab_2.ipynb) — работа с продажами, группировкой, заполнением пропусков и merge.
- [Практическая работа 3](lab_3.ipynb) — работа с файлами, объединять несколько источников в один `DataFrame`, заполнять пропуски и сохранять результат в формате parquet
- [Практическая работа 4](lab_4.ipynb) — временные ряды: дневные агрегаты заказов и событий, корреляция активности и выручки
- [Практическая работа 5](lab_5.ipynb) — оптимизация памяти и очистка данных, итоговый набор признаков `user_features`
- [Практическая работа 6](lab_6.ipynb) — интеграция источников, агрегаты по заказам, событиям и категориям, кодирование категориальных признаков и подготовка набора к обучению модели
